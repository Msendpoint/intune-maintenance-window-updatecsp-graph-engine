# Intune Maintenance Windows for Windows Updates That Stick (M365 SaaS Engine Ready)

> Creates and assigns an Intune Windows custom configuration profile using Windows Update CSP maintenance window OMA-URI settings via Microsoft Graph, with retries for 429/409 and on-endpoint validation guidance.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/intune-maintenance-window-updatecsp-graph-engine.git
cd intune-maintenance-window-updatecsp-graph-engine

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Microsoft Graph, Intune

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
